# MERN Blog Application (Vite + React)
A modern, high-performance blogging platform featuring full CRUD capabilities, built with the MERN stack and optimized with Vite for a superior developer experience.

---

###Tech Stack
* **Frontend:** React (Vite), Tailwind CSS, Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB with Mongoose for schema validation

### Key Features
* **Full CRUD Operations:** Users can seamlessly **Create, Read, Update, and Delete** blog posts.
* **Structured Data Modeling:** Implemented robust schema validation using **Mongoose** to ensure data integrity.
* **Vite Optimization:** Leveraged **Vite** for faster Hot Module Replacement (HMR) and optimized production builds.
* **Async API Handling:** Optimized backend with **Express.js** to handle asynchronous requests and provide stable API responses.
* **File Management:** Integrated **Multer** for efficient handling of image uploads (if applicable).
